PlanWise is an event-planning assistant for organizing corporate gatherings, birthdays, conferences, and student tech events. Enter the event type, location, expected attendance, budget, venue style, and weather forecast to receive a structured plan with budget allocations, city-specific venue and vendor recommendations, occasion-matched catering ideas, and weather-risk guidance.

Built with Streamlit and CrewAI, PlanWise combines agent-based planning with deterministic tools for budget calculations, vendor filtering, and risk checks. It can run locally without an LLM provider using its offline planning flow.

Vendor recommendations require a reviewed vendor_catalog.json file. That file is not included in this public repository because its contact details have not been cleared for release.
